## AskAetius ##

A MVP of a RAG web-app - select files from the frontend, RAG embeddings created in the backend, and then you can chat to your data.

Tech Stack:
- JS
- Express.js (Node.js)
- Pinecone (Embeddings and retrieval for RAG)
- Cohere (Free LLM for LLM-based query generation and answering using relevant queries).
